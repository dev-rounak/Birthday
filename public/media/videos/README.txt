Videos Folder
============

Place video files here (mp4, webm).

Each video is referenced in src/config.js section 5 (videos array).
Local file example: { title:"Birthday message", type:"file", src:"/media/videos/msg.mp4", poster:"/media/videos/msg.jpg" }
YouTube example: { title:"Our trip", type:"youtube", src:"https://www.youtube.com/watch?v=XXXXXXXXXXX" }

Poster images (thumbnail jpgs) can also be placed here.
